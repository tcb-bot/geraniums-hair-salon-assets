# Geraniums Hair Salon — Image Assets

This private repository preserves the original visual assets used by the Geraniums Hair Salon website.

The binary files are retained here for source control and backup. The production website serves its images from managed web asset storage rather than directly from this repository, preserving reliable builds and deployments.
